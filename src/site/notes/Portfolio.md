## Hands-On Projects & Infrastructure

### [PieSOC — Containerized Mini Security Operations Center](https://github.com/kirbywon/raspberry-pi-soc)
* Built and deployed **PieSOC**, a multi-node home network Security Operations Center running on a **Raspberry Pi 5** and **Raspberry Pi Zero 2 W**. Source code and deployment files available on [GitHub](https://github.com/kirbywon/raspberry-pi-soc).
* **Threat Detection (NIDS):** Configured **Suricata** to monitor live network interface traffic, inspect packets, and log security alerts.
* **DNS Filtering & Privacy:** Deployed **Pi-hole** chained with **Unbound** for recursive, encrypted DNS resolution and ad-blocking.
* **Observability & Telemetry Pipeline:** Built centralized monitoring dashboards using **Grafana**, aggregating logs with **Loki** and system metrics with **Prometheus**.
* **Secure Remote Access:** Configured a **Tailscale** mesh overlay network for encrypted management access to the PieSOC stack from anywhere.
